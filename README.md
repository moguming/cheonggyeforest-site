# 청계숲 공식 홈페이지 1차 시안

## 실행
index.html을 Chrome에서 열면 됩니다. 별도의 설치가 필요하지 않습니다.

## 기능
- 반응형 프리미엄 메인 페이지
- 세 매장 소개 및 상세 섹션
- 네이버 예약 링크(관리자에서 URL 등록 후 작동)
- 모바일 하단 전화/길찾기(관리자에서 전화번호/주소 등록 후 작동)
- ADMIN 메뉴에서 매장명, 소개, 사진 URL, 전화, 주소, 영업시간, 예약 URL 편집

## 주의
- ADMIN은 **시연용**으로 로그인/권한 보호가 없습니다. 저장 데이터는 현재 브라우저 localStorage에만 남으며 다른 기기나 방문자에게 반영되지 않습니다. 공개 운영 전 반드시 인증과 서버 DB로 교체해야 합니다.
- 초기 사진은 실제 매장 사진이 아닌 외부 참고 이미지입니다. 사용 권한을 확인한 실제 매장 사진으로 교체하세요.
- 실제 전화번호/주소/네이버 예약 URL은 확인되지 않아 비워 두었습니다.
- 외부 이미지 사용을 위해 인터넷 연결이 필요합니다.
- 배포: 정적 호스팅(Vercel, Netlify 등)에 index.html을 배포할 수 있습니다. 운영용 관리자 구축은 별도 단계입니다.
